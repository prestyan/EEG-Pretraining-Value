# Submit a New Model or Dataset

1. **Download** the [Excel submission template](Submission_Template.xlsx). On GitHub, use the file's download button if it opens a preview page.
2. **Fill in** the model/dataset name, author(s), contact email, evaluation protocol, and the mean Cohen's kappa scores for Frozen, Fine-tuned, and Scratch. PRR, ACS, and PVS are calculated automatically. Confirm the originality and authenticity declarations, and enter your name and date. Use one result row per model–dataset pair.
3. **Email** the completed Excel file to **shaoyang@nuaa.edu.cn** with the subject:

   ```text
   Request For New Models in Pretraining Value
   ```

The same process applies to results on a new dataset using existing models.

## Questions or Feedback

Please email **shaoyang@nuaa.edu.cn** directly with your question or feedback. No Excel form is required.
